# Obsah přednášek (1)

- Instalace, upgrade a migrace uživatelských dat
- Práce s bitovými kopiemi systému, správa virtuálních disků (VHD souborů)
- Správa a nasazení bitových kopií systému
- Nastavení sítě (protokoly IPv4 a IPv6, nástroje)
- Nastavení Windows Firewall, vzdálená správa
- Souborový systém NTFS, oprávnění, sdílení, EFS, BitLocker, soubory offline

# Obsah přednášek (2)

- Autentizace a autorizace, UAC, AppLocker
- Správa zařízení, ovladačů a disků, prostory úložišť, možnosti napájení
- Monitorování a výkon
- Zálohování a obnova dat
- Kompatibilita aplikací a VPN spojení
- Windows Update
