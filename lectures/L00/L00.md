# Přednášky

- Zaměřují se na správu Windows 11 (verze 24H2 a 25H2) v prostředí firmy či školy
  - Windows Server 2022/2025 tam, kde je potřeba serverová strana (doména, WSUS, RD Gateway)
  - Windows 10 (konec podpory 14. 10. 2025) jen jako historie a zdroj migrace
- Rozsahem přibližně odpovídají certifikaci **Microsoft MD-102 Endpoint Administrator**
  - Témata nemusí pokrývat veškerou látku potřebnou pro zvládnutí certifikační zkoušky!
- Vycházejí z dokumentace **Microsoft Learn** a z knihy
  - *Exam Ref MD-102 Microsoft Endpoint Administrator* (Andrew Warren, Microsoft Press, 2023)
- Přednášky jsou v Markdownu na GitHubu – chybu nahlaste, nebo rovnou opravte

# Obsah přednášek (1)

- **L01** Instalace, upgrade a migrace uživatelských dat (edice a životní cyklus Windows 11, USMT)
- **L02** Bitové kopie systému, Sysprep a konfigurační průchody, Windows PE, virtuální disky VHDX
- **L03** Správa a nasazení bitových kopií (DISM, ovladače, balíčky, Windows Autopilot a Intune)
- **L04** Nastavení sítě – IPv4 a IPv6, směrování, nástroje, bezdrátové sítě, tisk
- **L05** Windows Firewall, vzdálená plocha a vzdálená správa (WinRM, PowerShell, SSH)
- **L06** Sdílení a zabezpečení prostředků – NTFS, EFS, BitLocker, soubory offline

---

# Obsah přednášek (2)

- **L07** Řízení uživatelských účtů (UAC), autentizace, řízení spouštění aplikací (AppLocker, App Control)
- **L08** Správa zařízení, ovladačů a disků, Storage Spaces, možnosti napájení
- **L09** Monitorování a výkon – Zabezpečení Windows, Správce úloh, služby, Prohlížeč událostí, Sledování výkonu
- **L10** Zálohování a obnova dat, stínové kopie, Windows RE
- **L11** Kompatibilita aplikací, virtualizace pomocí Hyper-V, VPN
- **L12** Windows Update, WSUS a Windows Autopatch, Microsoft Edge

# Počítačová cvičení

- Probíhají v učebně **C304** na stanicích s Windows 11 Education 25H2 a Hyper-V
  - Virtuální stroje se staví nástrojem AutomatedLab, disk C: se po restartu vrací do výchozího stavu
- **Úvodní teorie** – slouží k bližšímu pochopení látky
  - Zejména při samostatném (offline) vypracování úkolů v případě absence na cvičení
- **Úkoly** (Lab 01–0x) – studenti vypracovávají **vše samostatně** podle detailního postupu
  - Na detaily a nejasnosti se ptají vyučujícího přímo na cvičení
- **Bodované úkoly** – podobné úkolům probíraným na daném cvičení

# Obsah počítačových cvičení

- **E01** Instalace, upgrade a migrace uživatelských dat (bezobslužná instalace Windows 11, USMT)
- **E02** Bitové kopie systému – WIM, DISM, Windows PE, Sysprep, boot z VHDX
- **E03** Síťování ve Windows, Windows Firewall, IP adresace, vzdálená správa
- **E04** Sdílení a zabezpečení prostředků – NTFS, EFS, soubory offline
- **E05** Řízení uživatelských účtů (UAC) a řízení spouštění aplikací
- **E06** Monitorování a výkon – služby, Prohlížeč událostí, Sledování výkonu
